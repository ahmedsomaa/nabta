Phase 1 — Foundation

Phase 1 Complete Historical specification — do not re-implement unless fixing regressions.

Status: Complete — monorepo, auth/RBAC (STUDENT, TEACHER, ADMIN, SYSTEM_ADMIN), portal shell (inset sidebar, school brand mark, role breadcrumbs, stone/zinc tokens), Prisma 7, CI/Docker, and wiring for all six client surfaces. Next: Phase 2 — Academic Core.

Goal

Establish the monorepo, full Docker development environment, CI/CD, authentication, RBAC, HeroUI v3, i18n scaffolding, light/dark mode, application layouts, and HeroUI agent tooling (MCP, Skills, agents-md).

In Scope

  • Monorepo structure (pnpm workspace + Turbo)
  • apps/web — React 19 + Vite + Tailwind CSS v4 + HeroUI v3 (@heroui/react + @heroui/styles)
  • apps/api — NestJS with modular architecture
  • packages/database — Prisma schema/client
  • packages/types, packages/validation, packages/config, packages/i18n
  • Docker Compose: PostgreSQL, Redis, MinIO, api, web
  • Dockerfiles: Dockerfile.api, Dockerfile.web
  • GitHub Actions CI: lint, test, build, Docker image build
  • Testing baseline: Jest (API), Vitest (web), at least one test each
  • Authentication (email/password, refresh tokens)
  • RBAC (STUDENT, TEACHER, ADMIN)
  • Design system with HeroUI theme overrides (Nabta --accent #10B981); light/dark; theme toggle in app shell
  • HeroUI agent tooling: .cursor/mcp.json (@heroui/react-mcp), Agent Skills (heroui-react), agents-md → docs/technical/heroui-agents.md + .heroui-docs/
  • i18n scaffolding: EN/AR shell strings (nav, auth, common UI)
  • Role-based application layouts (sidebar, mobile nav)
  • API architecture shell (/api/v1, health check)
  • MinIO storage service interface (S3-compatible)
  • Resend email service: EmailService + password reset email
  • RESEND_API_KEY, RESEND_FROM_EMAIL in .env.example
  • .env.example, README, dev scripts

Out of Scope

  • Marketing site (Phase 1b)
  • Academic entities (schools, classes, subjects)
  • Student/teacher/admin portal features
  • Assignments, assessments, notifications
  • File uploads beyond storage interface setup
  • Full translation of all features (rolls out per phase)

Acceptance Criteria

All criteria met.

  • Monorepo builds and runs with pnpm start / pnpm start:app (or pnpm dev)
  • pnpm docker:up starts PostgreSQL, Redis, and MinIO
  • pnpm docker:up:full starts api + web containers
  • GitHub Actions CI runs on PR (lint, test, build)
  • User can register/login with email/password
  • JWT + refresh token flow works
  • RBAC guards protect endpoints by role
  • Three role-based layouts render (student, teacher, admin)
  • Light/dark theme toggle works with persisted preference
  • EN/AR locale switcher works; Arabic renders RTL
  • HeroUI v3 initialized with Nabta accent tokens (#10B981 → --accent)
  • Official HeroUI MCP configured; Agent Skills installed; heroui-agents.md index present; Nabta root AGENTS.md preserved
  • Prisma migrations run successfully
  • At least one API and one web test pass in CI
  • Password reset email sends via Resend
