Goal

Build the platform operator console at apps/system-admin for SYSTEM_ADMIN users — school tenant management and platform health. Not school academic features.

Depends On

  • Phase 1 — Foundation (auth, design system, i18n, Docker)

In Scope

  • apps/system-admin — React 19 + Vite + Tailwind CSS v4 + HeroUI v3 (port 5175)
  • SYSTEM_ADMIN role + API guards
  • Operator auth shell and layout
  • School tenant list and basic CRUD
  • Platform health dashboard (API health check)
  • EN/AR with RTL via shared packages/i18n
  • Light and dark theme toggle
  • Dockerfile.system-admin and Docker Compose profile

Out of Scope

  • School academic features (classes, grades, assignments)
  • Student/teacher portal functionality
  • Billing or payment setup
  • Phase 2 academic entities

Acceptance Criteria

  • SYSTEM_ADMIN can log in to the console
  • Non–SYSTEM_ADMIN users are blocked
  • School list with create/edit works
  • Health page reflects API status
  • EN/AR and RTL work; light/dark themes work
  • Runs via Docker Compose (--profile full) on port 5175
