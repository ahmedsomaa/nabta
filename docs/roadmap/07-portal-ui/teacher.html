What shipped

  • Nav stays Home · Classes · Assignments · Quizzes · Gradebook. Attendance, lessons, students, and materials stay inside the class workspace.
  • Home is a work queue: greeting + dynamic subtitle, quick actions with inset icon wells, today’s classes (status + attendance), needs your attention as two columns (to-grade rows + alerts), recent activity.
  • Classes is a picker: My Classes header, search, All / Needs grading / Has quiz chips. Tiles use the student shell (inset accent hero) with teacher facts — students, schedule, to-grade, quiz count, today’s attendance when there is a slot. Opening a class uses tabs: Overview · Students · Lessons · Assignments · Quizzes · Attendance · Materials. Course builder stays a dedicated page.
  • Class workspace tabs match the job: Overview is a dashboard (metrics → today’s slots + attendance → upcoming work / to grade → activity); Students is a table with search and filters; Attendance pairs a distribution bar and per-status counts with a colour-coded segmented control per student, plus a single Mark all dropdown for bulk marking and unmarked students left explicitly unmarked; Assignments is a dense table (due, submissions, graded, status); Quizzes are cards with time limit, attempts, and completion; Lessons is a numbered learning path with material counts; Materials is a resource library — unit topics, search/type filters, a dense table, file and link uploads, edit/move/delete. Units are the topics; there is no parallel folder model.
  • Teacher APIs compose existing tables: dashboard recentActivity, slot studentCount / attendanceTaken, class-list stats, class-detail room / todaySlots / assessments + activity, assignment submissionCount / gradedCount, assessment timeLimitMinutes, attendance history, materials list with downloadUrl / url plus patch/delete, attendance_incomplete alerts. No archive filters, quiz “to review” queue, calendar, or messages.

Visual direction

  • Same 1px rounded-xl border border-border shells as student — no HeroUI Card as list/tile wrapper
  • HeroUI for controls: Button, Chip, Alert, ProgressBar, Radio, Toast, Skeleton, Modal
  • Import from apps/web/src/components/portal/PortalChrome.tsx, not from features/student/
  • Class tiles: student shell (padded card, inset accent hero, animated book) + teacher facts. No fake progress or archive chips
  • Class workspace tabs use the HeroUI primary (segmented pill) variant; portal filter chips stay for in-tab filtering
  • Token colors only. Logical CSS. Check ~375px
