What shipped

  • Nav: Home, My Classes, Assignments, Quizzes, Grades — no More tab, no GPA/attendance/profile
  • Chrome: bordered lists and panels (StudentList, StudentPanel), class-card hero tiles, PageTrail breadcrumbs

Visual direction (as shipped)

  • Calm academic richness — not neon, gamification, or a second brand color
  • Page chrome is a 1px rounded-xl border border-border shell with no shadow
  • HeroUI for controls (Button, Chip, Alert, ProgressBar, Radio, Checkbox, Toast, Skeleton) — not as the default list/tile wrapper
  • Color via tokens only: --accent / bg-accent/10, --warning, --danger, --success
  • Static Lucide on content; lucide-animated only on selected hover/empty CTAs

In scope

  • apps/web student routes: dashboard, classes, subject, lesson, assignments, quizzes/assessments, grades
  • Shared student primitives: page header, empty state, icon well, panel, list, skeletons, page trail
  • EN/AR + RTL; loading / empty / error / success per UX States

Out of scope

  • Teacher, school admin, system admin polish (next in this phase)
  • Notifications, BullMQ, announcements
  • New product domains or schema
  • Marketing site, mobile apps
  • GPA, attendance, profile, More nav

UI-supporting payloads

Existing /me endpoints from Phases 3 and 5. Small payload additions that only serve these screens (not Phase 8 features):

  • Subject schedule — timetable slots on the class page
  • Assignment file downloadUrl — signed URL for resources and submissions
  • Assessment latestAttemptId — load review after a finished attempt
  • Published assignment work displays as Graded when gradesPublishedAt is set
