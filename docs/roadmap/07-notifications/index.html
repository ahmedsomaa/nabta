Phase 7 — Notifications & Background Jobs

Phase 7 Implement this phase only. Do not implement Phase 8+ functionality.

Goal

Implement the notification center, Redis/BullMQ queues, event-driven notifications, announcements, and scheduled reminders.

In Scope

  • In-app notification center for all roles
  • Redis + BullMQ queue architecture
  • Event-driven notifications: assignment created/graded, quiz published, new material, grade published
  • Announcements (teacher → class/subject/grade, admin → school-wide)
  • Scheduled reminders (assignment due soon)
  • Notification emails via Resend (assignment, announcement, grade events)
  • User email preferences respected per notification type

Out of Scope

  • Push notifications
  • Audit logging

Acceptance Criteria

  • Notification center shows unread/read notifications per user
  • Assignment publish triggers student notification via queue
  • Grade publish triggers student notification
  • Teachers can post announcements to class/subject/grade
  • Admins can post school-wide announcements
  • Assignment due-soon reminders are scheduled
  • Notification processing is async via BullMQ
  • Notification emails send via Resend for opted-in users

Implementation slices

Derived from this phase’s acceptance criteria. Complete in order; each slice is independently verifiable. Do not implement Phase 8+.

  1. Notification center — in-app inbox for all roles; unread/read. Verify: the center shows unread/read notifications per user.
  2. Queues — Redis + BullMQ; event-driven jobs for assignment created/graded, quiz published, new material, grade published. Verify: assignment publish notifies students asynchronously via the queue.
  3. Announcements — teacher → class/subject/grade; admin → school-wide. Verify: both teacher and admin announcements reach the right audience.
  4. Reminders — scheduled assignment due-soon jobs. Verify: due-soon reminders are scheduled.
  5. Email — Resend for assignment, announcement, and grade events; per-type user preferences. Verify: emails send for opted-in users.
