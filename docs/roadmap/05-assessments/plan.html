In scope

  • Quiz builder: MCQ, multiple answer, true/false, short answer; time limit, max attempts, passing score, randomization
  • Student flow: overview → start → questions → submit → result / feedback
  • Auto-score on submit (objectives + short-answer exact match); immediate student results
  • GradeRecord rollup (percentage + letter); student grades list and subject drill-down
  • Teacher results (count, average, pass rate, per-student best) and gradebook quiz columns
  • EN/AR + RTL; loading / empty / error / success per UX States

Out of scope

  • Admin portal, school analytics dashboards, global search
  • BullMQ / quiz-published notifications / announcements
  • Essay, oral, teacher short-answer grading queue
  • GPA and configurable grading schemes
  • Student attendance view
  • apps/mobile-staff, TipTap

Locked API shape

Role prefixes, not generic /api/v1/assessments. Sequence diagram maps to student routes under /me.

  • Teacher: /api/v1/teacher/assessments (scoped by TeachingAssignment)
  • Student: /api/v1/me/assessments, /me/attempts, /me/grades (scoped by enrollment)

Slice 0 — Schema, seed, this plan

Goal: persist quizzes, attempts, and subject rollups. Tenant isolation (schoolId from JWT).

ModelRole
AssessmentClass + subject quiz; optional unitId; time limit, max attempts, passing score, randomize, publishedAt
Question / QuestionOptionPrompt, points, type; options (T/F = two rows; short-answer accepted strings are correct options)
AssessmentAttemptIN_PROGRESS / SUBMITTED / EXPIRED; questionOrder; expiresAt
AttemptAnswerSelected option ids and/or text
GradeRecordUnique student + class + subject; percentage and letter

Seed: one published 10A Mathematics quiz (mixed types, 10 min, 2 attempts, passing 60, randomization on). Omar has no attempt. One unpublished draft quiz stays hidden from students.

Verify: migration applies; draft quiz absent from student subject payload.

Slice 1 — APIs + scoring + GradeRecord

Module: apps/api/src/modules/assessments/. Shared scoring; GradeRecord recompute on quiz submit and assignment publish-grades.

Scoring: all-or-nothing per question. Short answer: trim + case-insensitive match against correct option text. passed = (score/maxScore)*100 >= passingScore. Best submitted attempt feeds the rollup. Equal weight with published assignment percentages. Letter bands A–F. Hide isCorrect until submit.

Verify: Nadia publishes; Omar starts/submits and is scored; second-school token cannot read the quiz; keys hidden before submit.

Slice 2 — Teacher quiz builder

Routes: /teacher/assessments, /new, /:id, /:id/results.

Create Quiz on the dashboard; Add quiz on the class hub / builder. Debounced autosave. Publish/unpublish.

Verify: Nadia builds a mixed-type quiz and publishes it.

Slice 3 — Student take flow

Routes: overview, attempt (countdown from expiresAt), result. Dashboard upcoming and subject page list published quizzes.

Verify: Omar overview → start → answer → submit → result. Remaining attempts and expiry are enforced.

Slice 4 — Teacher results + surfaces

Attempt count, average, pass rate, per-student best; review one attempt. Gradebook quiz columns. Low-score dashboard alert (below passing).

Verify: after Omar submits, Nadia sees his score in results and gradebook.

Slice 5 — Student grades view

Replace /student/grades placeholder. List: subject, percentage, letter. Detail: published assignment scores + submitted quiz attempts.

Verify: Omar’s grades page shows 10A Mathematics after he submits; unpublished assignment scores stay hidden.
