Phase 5 — Assessments

Phase 5 Complete Historical specification — do not re-implement unless fixing regressions. Quiz builder, student attempts, auto-score, and subject grades.

Status: Complete — teacher quiz builder, student take-and-score flow, GradeRecord rollups, and the student grades page. Admin analytics shipped in Phase 6. Next: Phase 7 — Notifications.

Goal

Build the assessment domain: quiz builder, questions, attempts, scoring, results, and assessment analytics.

In Scope

  • Quiz/assessment builder (teacher)
  • Question types: multiple choice, multiple answer, true/false, short answer
  • Configurable: time limit, attempts, passing score, question randomization
  • Student assessment flow: overview → start → questions → submit → result → feedback
  • Automatic scoring for objective questions
  • Assessment attempts tracking
  • Results and feedback display
  • Student grades view (subject-level grades)

Out of Scope

  • Admin portal
  • Notifications for quiz publish
  • Advanced exam types (essay, oral)

Acceptance Criteria

  • Teacher can create quiz with multiple question types
  • Student can take assessment with time limit and attempt tracking
  • Objective questions are auto-scored
  • Student sees results and feedback after submission
  • Student grades page shows subject-level current grades
  • Assessment domain is extensible for future exam types

Implementation slices

Derived from this phase’s acceptance criteria. Data models, APIs, and seed are slices 0–1 in the detailed plan. Do not implement Phase 6+ here.

  1. Quiz builder — multiple choice, multiple answer, true/false, short answer. Verify: teacher can create a quiz with multiple question types.
  2. Attempt rules — time limit, attempts, passing score, question randomization. Verify: a student attempt respects those settings.
  3. Student flow — overview → start → questions → submit → result → feedback. Verify: student can take an assessment with time limit and attempt tracking.
  4. Scoring — automatic scoring for objective questions; results and feedback after submit. Verify: objective questions are auto-scored and the student sees results.
  5. Grades view — subject-level current grades; domain extensible for future exam types. Verify: student grades page shows subject-level grades.
