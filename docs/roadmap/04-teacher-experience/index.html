Phase 4 — Teacher Experience

Phase 4 Complete Historical specification — do not re-implement unless fixing regressions. Teacher portal, teacher-scoped APIs, grading, and attendance.

Status: Complete — teacher dashboard, class roster, course builder, assignment create/publish, grading, gradebook, and attendance. Quizzes shipped in Phase 5. Next: Phase 6 — Administration (complete) · Phase 7 — Portal UI (current).

Goal

Build the teacher portal: dashboard, class management, course/subject builder, assignment creation, submission management, gradebook, and feedback.

In Scope

  • Teacher dashboard (today's classes, to-grade, alerts, quick actions)
  • Class management (student table, progress, attendance, missing work)
  • Course/subject builder (units, lessons, drag-and-drop reorder)
  • Material upload (video, text, PDF)
  • Assignment creation, publish, due date, attachments
  • Submission management (view, grade, feedback)
  • Gradebook view
  • Attendance recording per class session
  • Complete assignment workflow end-to-end

Out of Scope

  • Quiz/assessment builder
  • Admin portal
  • Notifications (assignment publish won't notify yet)
  • Analytics dashboards

Acceptance Criteria

  • Teacher dashboard shows today's classes and to-grade queue
  • Teacher can build course content with units and lessons
  • Teacher can create and publish assignments
  • Students can submit (from Phase 3) and teacher can grade
  • Teacher can add feedback and publish grades
  • Teacher can record attendance per session
  • Complete workflow: create → publish → students submit → grade → feedback

Implementation slices

Derived from this phase’s acceptance criteria. Data models, teacher APIs, and seed deltas are slices 0–1 in the detailed plan — complete those first. Then proceed in order. Do not implement Phase 5+.

  1. Teacher dashboard — today’s classes, to-grade queue, alerts, quick actions. Verify: dashboard shows today’s classes and to-grade queue.
  2. Course builder — units, lessons, drag-and-drop reorder, material upload. Verify: teacher can build course content with units and lessons.
  3. Assignments — create, publish, due date, attachments. Verify: teacher can create and publish assignments.
  4. Grading + gradebook — view submissions, grade, feedback, publish grades. Verify: students can submit (Phase 3) and teacher can grade with feedback.
  5. Attendance + workflow — record attendance per session; complete create → publish → submit → grade → feedback. Verify: attendance records and the end-to-end assignment workflow succeed.
