Phase 4 Complete Historical execution plan — teacher portal, teacher-scoped APIs, grading, and attendance.

Companion to Phase 4 — Teacher Experience (scope guards and acceptance criteria). This page is the execution plan: schema deltas, teacher APIs, seed, and apps/web screens. Slices 0–1 are data/API prerequisites; later slices map to the phase index plus class management.

Web teacher portal only. Quiz builder is Phase 5. Notifications are Phase 7. Keep student /student/grades as a later-phase placeholder. Do not implement apps/mobile-staff, GradeRecord, or GPA.

Slice order

Slices 0–1 first. Then dashboard → classes → builder → assignments → grading → attendance. Sequential; each slice is independently verifiable.

In scope

  • Dashboard: today’s timetable, to-grade queue, assignment-based alerts, in-scope quick actions
  • Class management: roster (progress, attendance %, assignment average, missing work) and student overview
  • Course builder: units, lessons, reorder, materials, publish/unpublish, autosave
  • Assignment create / edit / publish / due date / attachments
  • Grade submissions, feedback, publish grades; gradebook matrix
  • Attendance per class session (Present / Absent / Late / Excused)
  • Student assignment page shows score and feedback after grades are published
  • EN/AR + RTL; loading / empty / error / success per UX States

Out of scope

  • Create Quiz, Post Announcement
  • Low assessment-performance alerts
  • BullMQ / in-app notifications
  • GradeRecord, term GPA, student grades page (Phase 5)
  • Student attendance view
  • TipTap / full WYSIWYG — TextArea for rich text; URL fields for other lesson types
  • Global search, admin portal, apps/mobile-staff

Slice 0 — Schema, seed, student publish filter

Goal: persist grading, publish, attachments, and attendance. Tenant isolation (schoolId from JWT).

ChangeRole
Lesson.publishedAtStudents only see published lessons
Assignment.maxScoreDefault 100
AssignmentFileTeacher attachments; keys {schoolId}/assignments/{assignmentId}/{uuid}.{ext}
Submission grade fieldsscore, feedback, gradedAt, gradesPublishedAt
AttendanceSession / AttendanceRecordPer class+subject+date; statuses Present / Absent / Late / Excused

Do not add Assessment, Question, GradeRecord, Notification, or AuditLog.

Seed: publish existing Math lessons; add one unpublished draft lesson; seed Omar’s submission on the soon-due assignment as SUBMITTED.

Verify: unpublished lesson hidden from student subject page; Omar has a submitted row.

Slice 1 — Teacher APIs + storage

Module: apps/api/src/modules/teacher/. Role TEACHER + TenantGuard. Scope by TeachingAssignment.

Key endpoints under /api/v1/teacher: /me, /dashboard, classes/roster, units/lessons CRUD and reorder, publish, materials, assignments CRUD and publish, submissions grade and publish-grades, gradebook, attendance, files/presign.

Rules: draft assignments stay invisible to students. PATCH score → GRADED. Student APIs hide score until gradesPublishedAt. POST .../publish-grades sets RETURNED. No BullMQ.

Verify: Nadia loads dashboard and grades Omar; a second-school token cannot.

Slice 2 — Dashboard

Route: /teacher/dashboard. Greeting uses given name Nadia.

  • Today’s classes from TimetableSlot
  • To-grade queue (SUBMITTED + LATE counts)
  • Alerts: missing work, low lesson progress
  • Quick actions: Create Assignment, Upload Material, Take Attendance — not Quiz or Announcement

Verify: teacher login shows schedule and Omar’s seeded submission in to-grade.

Slice 3 — Classes + roster

Routes: /teacher/classes, /teacher/classes/:classId/:subjectId, student overview nested under that hub.

Roster columns: Student, Progress, Attendance, Average, Missing Work. Average uses published-grade assignment scores only.

Verify: Nadia opens 10A Mathematics and sees Omar.

Slice 4 — Course builder

Route: /teacher/classes/:classId/:subjectId/builder

Add/rename/delete units and lessons; drag-and-drop reorder; lesson editor; material upload; publish/unpublish; debounced autosave.

Verify: Nadia publishes a lesson; Omar sees it. Draft stays hidden.

Slice 5 — Assignments create / publish

Routes: /teacher/assignments, /teacher/assignments/new, /teacher/assignments/:id

Title, instructions, due date, class+subject locked to teaching assignments, max score, attachments, draft, publish.

Verify: published assignment appears on Omar’s list.

Slice 6 — Grading + gradebook + student reveal

Routes: submissions queue, /teacher/gradebook and per class/subject matrix.

Student assignment detail gains optional score, maxScore, feedback after gradesPublishedAt.

Verify: grade → publish → Omar sees score. Before publish he still sees Submitted/Late only.

Slice 7 — Attendance + UX + e2e

Route: /teacher/classes/:classId/:subjectId/attendance

Bulk record for a date. Toast on success. Dashboard Take Attendance deep-links here. Every screen has loading, empty, error, success. Nested URLs keep the parent nav item active.

End-to-end: Nadia publishes assignment → Omar submits → Nadia grades and publishes grades → Omar sees feedback → Nadia records attendance.
