Phase 3 — Student Experience

Phase 3 Current Implement this phase only. Do not implement Phase 4+ functionality.

Current phase. Phase 2 Academic Core is complete. Start here for the student portal.

Goal

Build the student portal: dashboard, my classes, subject pages, lessons, materials, assignments, and progress tracking.

In Scope

  • Student dashboard (schedule, upcoming, continue learning, overview)
  • My Classes — list enrolled subjects
  • Subject page (teacher, units, lessons, materials, assignments, progress)
  • Lesson viewer (video, rich text, PDF, images, external resources)
  • Lesson progress tracking
  • Assignment view, upload, submit, status display
  • File upload for submissions (storage abstraction)

Out of Scope

  • Teacher portal (assignment creation, grading)
  • Assessments/quizzes
  • Grades view (partial — status only, not full gradebook)
  • Attendance view
  • Notifications

Acceptance Criteria

  • Student dashboard shows today's schedule and upcoming work
  • Student can browse enrolled subjects and open lessons
  • Lesson progress is tracked
  • Student can view assignment instructions and submit files
  • Assignment status updates to "Submitted" after submission
  • All screens have loading, empty, and error states
  • Mobile-responsive student navigation works

Implementation slices

Derived from this phase’s acceptance criteria. Complete in order; each slice is independently verifiable. Do not implement Phase 4+.

  1. Student dashboard — today’s schedule, upcoming work, continue learning. Verify: dashboard shows schedule and upcoming work.
  2. Classes + subject page — enrolled subjects list; subject page with teacher, units, lessons, materials, assignments, progress. Verify: student can browse enrolled subjects.
  3. Lesson viewer + progress — video, rich text, PDF, images, external resources; progress tracking. Verify: student can open lessons and progress is tracked.
  4. Assignments — view instructions, upload files, submit, status display. Verify: submit updates status to “Submitted”.
  5. UX + mobile — loading, empty, and error states; mobile-responsive student navigation. Verify: no blank screens; mobile nav works.
