Phase 6 — Administration

Phase 6 Implement this phase only. Do not implement Phase 7+ functionality.

Goal

Build the admin portal: dashboard, user management, academic management UI, teacher/student assignments, school configuration, and analytics.

In Scope

  • Admin dashboard (school overview, academic overview with filters)
  • Student management (searchable table, view/edit/assign/deactivate)
  • Teacher management (assign subjects/classes, deactivate)
  • Academic structure management UI (years, grades, classes, subjects)
  • Teacher/student assignment workflows
  • School configuration and settings
  • Basic analytics (attendance, assignment completion, performance)
  • Global search

Out of Scope

  • Notifications
  • Audit logging UI
  • Multi-school admin

Acceptance Criteria

  • Admin dashboard shows school overview with key metrics
  • Admin can CRUD students and teachers via UI
  • Admin can manage academic structure via UI
  • Admin can assign teachers to classes/subjects and students to classes
  • Global search returns results across entities
  • Complete workflow: login → academic mgmt → assign teacher/students/subjects

Implementation slices

Derived from this phase’s acceptance criteria. Complete in order; each slice is independently verifiable. Do not implement Phase 7+.

  1. Admin dashboard — school overview and academic overview with filters. Verify: dashboard shows school overview with key metrics.
  2. People UI — searchable student and teacher tables; view/edit/assign/deactivate. Verify: admin can CRUD students and teachers via UI.
  3. Academic structure UI — years, grades, classes, subjects. Verify: admin can manage the hierarchy via UI.
  4. Assignments — teachers to classes/subjects; students to classes. Verify: admin can assign teachers and students.
  5. Search + workflow — global search across entities; login → academic mgmt → assign. Verify: search returns results; the complete admin workflow succeeds.
