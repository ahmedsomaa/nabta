Phase 1b — Marketing Site

Phase 1b Implement this phase only. Depends on Phase 1. Do not implement Phase 2+ functionality.

Goal

Build the public marketing website at apps/marketing — separate from LMS portals. Attract schools and drive demo requests.

Depends On

  • Phase 1 — Foundation (design system, i18n scaffolding, Docker)

In Scope

  • apps/marketing — React 19 + Vite + Tailwind CSS v4 + HeroUI v3
  • Pages: Home, Features, For Schools, Pricing (placeholder), Contact/Demo
  • EN/AR with RTL support via shared packages/i18n
  • Light and dark theme toggle
  • Login link to apps/web
  • Contact/demo form submission
  • Responsive design (mobile-first)
  • Dockerfile.marketing and Docker Compose profile
  • Deploy to Cloudflare Pages or Vercel (free tier)

Out of Scope

  • LMS portal features or authentication
  • Blog or CMS
  • Payment or signup flows
  • Academic entities (Phase 2)

Acceptance Criteria

  • All v1 pages render in EN and AR with correct RTL
  • Light and dark themes work on all pages
  • Login link navigates to LMS app
  • Contact/demo form submits successfully
  • Site is responsive at all breakpoints
  • Runs via Docker Compose (--profile full)
  • Deployed to free hosting (Cloudflare Pages or Vercel)

Implementation slices

Derived from this phase’s acceptance criteria. Complete in order; each slice is independently verifiable. Do not implement Phase 1c+ or Phase 2+.

  1. Marketing app scaffold — apps/marketing with React 19 + Vite + Tailwind v4 + HeroUI v3; Dockerfile.marketing and Compose profile. Verify: the app runs via Docker Compose --profile full on port 5174.
  2. v1 pages — Home, Features, For Schools, Pricing (placeholder), Contact/Demo. Verify: all pages render.
  3. EN/AR + RTL — shared packages/i18n. Verify: all v1 pages render in EN and AR with correct RTL.
  4. Theme — light and dark toggle on every marketing page. Verify: both themes work on all pages.
  5. Login + contact — login link to apps/web; contact/demo form submits. Verify: login navigates to the LMS app; form submission succeeds.
  6. Responsive + deploy — mobile-first at specified breakpoints; free-tier host (Cloudflare Pages or Vercel). Verify: responsive at all breakpoints; site deployed.
