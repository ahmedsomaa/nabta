Goal

Scaffold the native staff app at apps/mobile-staff for teachers and school admins — role-aware navigation, auth, EN/AR, and Nabta theme.

Depends On

  • Phase 1 — Foundation (auth API, RBAC, i18n packages)

In Scope

  • apps/mobile-staff — Expo (~54) + Expo Router + HeroUI Native + Uniwind
  • TEACHER and ADMIN login (reject STUDENT, SYSTEM_ADMIN)
  • Role-specific tab navigation shells (placeholders)
  • EN/AR via shared packages/i18n; RTL layout
  • Light/dark theme (Nabta green accent)
  • EXPO_PUBLIC_API_URL configuration
  • pnpm dev:mobile-staff script

Out of Scope

  • Gradebook, attendance, admin CRUD (Phase 4/6+)
  • Push notifications and offline sync (future)
  • Student mobile app (Phase 1d)
  • Academic entities (Phase 2)

Acceptance Criteria

  • Teacher can log in and see teacher tab shell
  • School admin can log in and see admin tab shell
  • Student and SYSTEM_ADMIN logins rejected
  • EN/AR and RTL work; light/dark themes work
  • API reachable via EXPO_PUBLIC_API_URL
  • Expo dev server starts with pnpm dev:mobile-staff
