Product Vision

Nabta (نَبْتَة) — Learn. Grow. Thrive. A modern school platform for Egyptian international schools. Not a generic online-course marketplace.

Purpose

Nabta is a production-quality learning platform that supports the day-to-day academic workflows of an international school: students, teachers, classes, subjects, academic years, grades, assignments, assessments, attendance, announcements, learning materials, and academic progress.

What This System Is

The platform sits between:

  • LMS (learning management)
  • Student Information System
  • Academic management platform
  • Digital classroom
  • Assessment platform

The primary goal is to make learning and academic management significantly easier.

Three Primary Experiences

PortalCore Question
Student"What do I need to learn or do today?"
Teacher"What do I need to teach, grade, or manage today?"
Admin"What is happening across the school?"

Architecture must allow additional roles (parents, coordinators, principals, counselors, school staff) to be added later without rewriting the system.

Target Environment

Designed for Egyptian international schools supporting common structures:

  • British curriculum
  • American curriculum
  • IB-style structures

Do not hardcode curriculum-specific assumptions into the core architecture. Curriculum-specific functionality should be configurable.

Non-Goals

  • Not a generic MOOC or online-course marketplace
  • Not an old-school ERP with dense, noisy interfaces
  • Not a gamified learning app

Quality Priorities

  • Clarity, speed, simplicity
  • Accessibility and responsive design
  • Strong information hierarchy
  • Smooth interactions
  • Reliable data
  • Scalable architecture
  • Bilingual EN/AR support with RTL

The interface should feel like a modern SaaS product — fast, modern, calm, reliable, professional. See Internationalization for language requirements.

Acceptance Criteria

  • Three distinct portal experiences exist (student, teacher, admin)
  • UI feels modern and calm, not like a generic admin template
  • Core architecture does not assume a single curriculum type
  • System is designed for extensibility to future roles
