Academic Overview

Subject grades and assignment completion belong here. GPA, attendance %, and analytics-heavy dashboards are later product — do not imply they shipped with the current web portal.

My Classes

List enrolled subjects. Each opens a subject page with:

  • Teacher, class, progress
  • Lessons, assignments, quizzes
  • Announcements — later product (Phase 8)

Learning Experience

Focused lesson interface with content area and course/unit navigation sidebar.

Support: video, rich text, PDFs, images, external resources, downloadable files, embedded content. Track lesson progress.

Assignments (Student View)

Students can view instructions, due date, resources, upload/replace submission before deadline, submit, and view status, grade, and feedback.

Statuses (owned by teacher workflow — see Teacher Portal):

Not Started → Draft → Submitted → Late → Graded → Returned

Assessments (Student View)

The current web nav labels this Quizzes. Flow: Overview → Start → Questions → Submit → Result → Feedback

Question types: multiple choice, multiple answer, true/false, short answer.

Grades

Subject-level current grades. Clicking a subject shows assessments, assignments, scores, feedback, grade history.

Grading schemes are configurable per school (percentage, letter, GPA, IB-style, custom).

Attendance (Student View)

Later product — not in the current web nav. When built: Present, Absent, Late, Excused, with percentage and counts.

Also Available

Later product (not implied as shipped):

  • Announcements and notifications (Phase 8)
  • GPA / academic average
  • Profile management

Upcoming deadlines already appear on Home and Assignments.

Navigation

Current web portal:

Home | My Classes | Assignments | Quizzes | Grades

Attendance, announcements, profile, and GPA are later — not a More tab today. Composition recipes: Portal Patterns.

Acceptance Criteria

  • Dashboard shows today's schedule, upcoming work, and continue learning
  • Student can browse enrolled subjects and open lesson content
  • Student can submit assignments and see status/grade/feedback
  • Student can take quizzes and view results
  • Student can view subject grades
  • Complete workflow works: login → dashboard → subject → assignment → submit → see grade
