The most focused experience — answers: "What should I do today?"

Dashboard

Stats

Four tiles: subject count, actionable assignments, upcoming quizzes, and mean lesson progress. No invented GPA or term-over-term delta.

Today's Tasks

Hero list beside Upcoming. Each row: kind, subject, due, status, and a quick action. Accent for actionable items; danger text for overdue.

Upcoming

Next items that are not already in Today's Tasks (capped at 7). Compact date + title.

Continue Learning

Most recently accessed lesson: subject, lesson title, progress, Continue.

Recent grades

Last few graded assignments and scored quizzes, with an empty state when none exist.

Announcements

Layout slot only — school/class announcements are later product (Phase 8). No announcement API or nav item.

Subjects

Tile grid of enrolled subjects: subject name, teacher, inset icon hero, lesson/assignment/quiz counts with icons, and progress. Client chips: All | In progress | Completed. Each subject opens a workspace on the same URL with local tabs: 

Overview | Lessons | Assignments | Quizzes

Subject tabs use the secondary variant. Lessons, Assignments, and Quizzes show totals.

The subject header carries a back link to Subjects, an icon hero with the subject name and code, and a borderless label/value table for teacher, class (the homeroom section, e.g. 1C), and schedule.

  • Overview — Continue Learning hero (unit – lesson, subject progress bar, Continue), then To Do (next 3 items with icons) beside Your Progress (large percent + lesson count), then Recent Activity (completed lessons and scored work with relative dates). Not a full assignment/quiz list.
  • Lessons — numbered path (01, 02, …) with All / In progress / Completed chips. Completed, in progress + Continue, or not started. No lock model; every published lesson stays open. No intra-lesson percent.
  • Assignments / Quizzes — subject-scoped cards (no subject name on the row): All / To Do / Submitted / Graded (assignments) or All / To Do / Completed (quizzes), due or score, and Open / View or Start / View results. No invented descriptions or quiz due dates.
  • Announcements — later product (Phase 8)

Learning Experience

Focused lesson interface with content area and course/unit navigation sidebar.

Support: video, rich text, PDFs, images, external resources, downloadable files, embedded content. Track lesson progress.

Assignments (Student View)

Global queue (not cards): inline summary To Do · Due soon · Overdue · Completed (overdue uses danger text). Tabs: All | To Do | Submitted | Graded, with superscript counts. Sort: due date earliest (default), due date latest, recently added, recently graded. Dense rows: status icon, title, subject · points · attachments, human due date (Due tomorrow / Sep 10 / Overdue · Sep 3), and Open / View. Graded rows show the published score. Students can view instructions, due date, resources, upload/replace submission before deadline, submit, and view status, grade, and feedback.

Statuses (owned by teacher workflow — see Teacher Portal): 

Not Started → Draft → Submitted → Late → Graded → Returned

To Do includes Not started, Draft, Returned, and Late. Submitted and Graded have their own tabs.

Assessments (Student View)

The current web nav labels this Quizzes. Global page uses cards (not the assignment work-queue list). Tabs: All | To Do | Completed | Results, with superscript counts. Sort: recently added (default), recently completed, highest score. In-progress quizzes pin first. Each card shows subject, questions, time limit, attempts, and a Start / Continue / View results action. In progress shows answered count and a thin bar. Completed and Results show score as 18/20 and percent. Cards open the overview (the start gate). Flow: Overview → Start modal → Attempt (one question) → Submit confirm → Result.

Overview: title and subject, a facts card (questions, time limit or none, attempts used of max, points), teacher instructions as written, and a generated “Before you begin” list from real rules only (time, attempts, auto-submit if timed). Timed quizzes warn that the timer starts on start. Start opens a confirm modal; Continue (in progress) skips it. A prior result is a score plus a link, not an embedded review.

Attempt: sidebar and bottom nav are hidden; the attempt top bar is the only chrome (exit, title, timer). One question at a time, with Previous / Next, a numbered navigator (desktop column, mobile modal), save status, and a submit confirm that shows answered and unanswered counts. Exit confirms leave; progress stays saved. Result uses the normal shell: large score and percent, passed/failed, question count, duration when start and submit times exist, then answer review. No due dates, praise copy, or invented descriptions.

Question types: multiple choice, multiple answer, true/false, short answer.

Grades

A read-only performance hub, not a to-do queue. Header plus a large overall average (mean of scored subjects only) with a progress bar. Compact subject list: name, %, bar, and letter when the school has one — desktop rows, mobile stacked cards. Recent grades link to the assignment or quiz. Clicking a subject still opens that subject’s assignments, quizzes, scores, and feedback.

No qualitative “Excellent” labels, last-term comparison, leaderboards, or invented categories. Year/term selectors, category weights, and a trend chart appear when the API provides them. Grading schemes are configurable per school (percentage, letter, GPA, IB-style, custom).

Attendance (Student View)

Later product — not in the current web nav. When built: Present, Absent, Late, Excused, with percentage and counts.

Navigation

Current web portal:

Home | Subjects | Assignments | Quizzes | Grades

Calendar, messages, notifications, attendance, announcements, profile, and GPA are later — not extra nav items today. Composition recipes: Portal Patterns.

Acceptance Criteria

  • Home shows greeting, four stats, today's tasks beside upcoming, continue learning, recent grades, and an announcements later-slot
  • Student breadcrumbs start at Home; teacher/admin breadcrumbs still start with the role
  • Subjects tiles show teacher, lesson/assignment/quiz counts, and progress; subject page has Overview / Lessons / Assignments / Quizzes tabs
  • Assignments use All / To Do / Submitted / Graded tabs; Quizzes use All / To Do / Completed / Results cards
  • Grades is a performance hub (overall average, subject list, recent grades)
  • Student can submit assignments and see status/grade/feedback
  • Student can take quizzes and view results
  • Complete workflow works: login → Home → task or subject → assignment → submit → see grade
