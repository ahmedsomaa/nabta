Mobile Student

Native student app — assignments, grades, and notifications on iOS and Android.

Purpose

Give students a mobile-first experience for daily school tasks. Lives at apps/mobile-student. Another API client — same /api/v1 as web portals.

v1 Capabilities (Phase 1d bootstrap)

AreaContent
AuthStudent login (email/password); JWT stored securely
HomeDashboard placeholder — welcome, quick links
NavigationExpo Router tab/stack shell
ThemeHeroUI Native + Uniwind; Nabta green accent; light/dark
i18nEN/AR via shared packages/i18n; RTL layout

Stack

  • Expo (~54) + Expo Router
  • HeroUI Native + Uniwind (Tailwind v4 for React Native)
  • Shared packages/types, packages/validation, packages/i18n
  • EXPO_PUBLIC_API_URL for API base URL
  • pnpm dev:mobile-student → Expo dev server

In Scope (Phase 1d)

  • apps/mobile-student scaffold with auth and tab navigation
  • Student role enforcement on login
  • EN/AR locale switcher; RTL support
  • Light/dark theme aligned to Nabta tokens
  • HeroUI Native component baseline

Out of Scope

  • Full assignment, grade, and lesson flows (Phase 3+)
  • Push notifications (future — see Future Roadmap)
  • Offline material download
  • Teacher or admin features

Acceptance Criteria

  • Student can log in via the mobile app
  • Non-student roles are rejected at login
  • Tab navigation shell renders with placeholder screens
  • EN/AR switch works; Arabic renders RTL
  • Light/dark theme works
  • App connects to API via EXPO_PUBLIC_API_URL
  • Expo dev server starts with pnpm dev:mobile-student
