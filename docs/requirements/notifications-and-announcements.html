Notifications & Announcements

Extensible notification system with in-app delivery, Resend email (Phase 7), and future push channels.

Notification Channels

  • In-app — Phase 7
  • Email — via Resend in Phase 7 (auth emails in Phase 1 — see Email)
  • Push notifications — future

Notification Events

  • Assignment created
  • Assignment due soon
  • Assignment graded
  • New announcement
  • Quiz published
  • New material uploaded
  • Attendance event
  • Grade published

Use Redis/BullMQ for asynchronous notification processing.

Announcements

Targeting

  • Teachers can publish to: class, subject, grade
  • Admins can publish school-wide announcements

Fields

  • Title, rich text, attachments
  • Publish date, expiry date
  • Target audience

Acceptance Criteria

  • In-app notification center exists for all roles
  • Assignment publish triggers student notification
  • Grade publish triggers student notification
  • Teachers can post announcements to class/subject/grade
  • Admins can post school-wide announcements
  • Notification processing uses async queue (BullMQ)
  • Notification emails send via Resend
