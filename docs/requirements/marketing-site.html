Marketing Site

Public-facing website to promote the platform to Egyptian international schools — separate from LMS portals.

Purpose

Attract and inform prospective schools, parents, and educators. Drive demo requests and provide a professional brand presence. Lives at apps/marketing in the monorepo.

v1 Site

One landing page. Navbar items scroll to sections (Namya Khan). Sticky CTA and demo buttons scroll to #contact. Old paths /features, /for-schools, /pricing, /contact redirect to the matching hash.

SectionContent
HeroHome USP, product visual, social proof. Primary CTA → #contact; secondary → #features
Features #featuresBenefits 2×2: structure, portals, i18n, assessment
For Schools #for-schoolsHow it works — adopt steps: structure → people → year
TestimonialsPlaceholder quotes (labeled)
Pricing #pricingTalk-to-us offer (no public list). Card CTA → #contact
FAQPrice, curriculum, bilingual, hosting, demo
Contact / Demo #contactForm as the final CTA. Submits to POST /api/v1/marketing/contact

Header includes: Login link to apps/web, locale switcher (EN/AR), theme toggle (light/dark). Sticky navbar CTA: Request a demo → #contact.

Stack

  • React 19 + Vite + Tailwind CSS v4 + HeroUI v3 (@heroui/react + @heroui/styles)
  • Shared packages/i18n for EN/AR
  • Light and dark mode
  • Same design tokens as Nabta portals (HeroUI --accent #10B981)

In Scope (Phase 1b)

  • One-page landing with section nav listed above
  • Responsive design (mobile-first)
  • EN/AR with RTL support
  • Light/dark theme toggle
  • Login link to LMS app
  • Contact/demo form (can submit to API or external service)

Out of Scope

  • LMS portal features or authentication
  • Blog or content management system
  • Payment or signup flows
  • Parent portal

Deployment

Deploy to Cloudflare Pages or Vercel (free tier). Separate domain or subdomain (e.g. www vs app).

Acceptance Criteria

  • One-page landing renders correctly in EN and AR
  • RTL layout works for Arabic
  • Light and dark themes work on all sections
  • Navbar items scroll to in-page sections
  • Login link navigates to LMS app
  • Contact/demo form submits successfully
  • Site is responsive at all breakpoints
  • Deployed to free hosting (Cloudflare Pages or Vercel)
