Nabta

Mobile Staff

Native app for teachers and school admins — grading and school ops on the go.

Purpose

Serve TEACHER and school ADMIN roles from one mobile client at apps/mobile-staff. Role-aware navigation after login. Not for SYSTEM_ADMIN or students.

v1 Capabilities (Phase 1e bootstrap)

AreaContent
AuthTeacher or school admin login; role detected post-auth
Teacher homeDashboard placeholder — classes, quick actions
Admin homeDashboard placeholder — school overview stub
NavigationRole-specific tab shell via Expo Router
Theme + i18nHeroUI Native, Nabta tokens, EN/AR, RTL

Stack

  • Expo (~54) + Expo Router
  • HeroUI Native + Uniwind
  • Shared packages/types, packages/validation, packages/i18n
  • EXPO_PUBLIC_API_URL for API base URL
  • pnpm dev:mobile-staff → Expo dev server

In Scope (Phase 1e)

  • apps/mobile-staff scaffold with auth and role-based navigation
  • TEACHER and ADMIN role support; reject STUDENT and SYSTEM_ADMIN
  • Separate tab layouts per role (placeholders)
  • EN/AR locale switcher; RTL support
  • Light/dark theme aligned to Nabta tokens

Out of Scope

  • Full gradebook, attendance, or admin CRUD (Phase 4/6+)
  • Push notifications and offline sync (future)
  • SYSTEM_ADMIN platform ops
  • Student features

Acceptance Criteria

  • Teacher can log in and see teacher tab shell
  • School admin can log in and see admin tab shell
  • Student and SYSTEM_ADMIN logins are rejected
  • EN/AR switch works; Arabic renders RTL
  • Light/dark theme works
  • App connects to API via EXPO_PUBLIC_API_URL
  • Expo dev server starts with pnpm dev:mobile-staff
