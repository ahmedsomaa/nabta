Course / Subject Builder

Content creation must be extremely simple. Structure:

Subject
 ├── Unit 1
 │    ├── Lesson 1
 │    ├── Lesson 2
 │    └── Quiz
 ├── Unit 2
 │    ├── Lesson 1
 │    └── Assignment

Teachers can: add unit, add lesson, reorder content (drag-and-drop), upload materials, add video/text, create quiz/assignment, publish/unpublish. Autosave drafts where appropriate.

Assignment Workflow (Owner)

Teachers own the assignment lifecycle:

  1. Create assignment (title, description, due date, attachments)
  2. Publish → students receive notification
  3. Students submit
  4. Teacher opens submissions, grades, adds feedback
  5. Publishes grades → students notified

Statuses: Not Started, Draft, Submitted, Late, Graded, Returned

Attendance (Teacher View)

Record attendance per class/session: Present, Absent, Late, Excused.

Acceptance Criteria

  • Dashboard shows today's classes, to-grade queue, and quick actions
  • Teacher can build course content with units, lessons, and materials
  • Teacher can create, publish, and grade assignments
  • Teacher can record attendance per class session
  • Teacher can view student progress and alerts
  • Complete workflow works: login → class → create assignment → students submit → grade → publish
