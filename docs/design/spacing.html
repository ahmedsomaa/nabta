Spacing & Shape

4px base scale, soft radius, restrained elevation — calm school UI on HeroUI defaults.

Spacing scale

Use a 4px base (HeroUI / Tailwind-aligned). Prefer consistent gaps over one-off padding.

SteppxTypical use
14Icon gaps, tight chip padding

1248Hero / empty-state breathing room

Radius

Drive from HeroUI --radius (default soft, ~0.5–0.75rem). Prefer medium rounded controls — not sharp brutalism, not pill overload.

  • --radius-sm — chips, small inputs
  • --radius / md — buttons, cards
  • --radius-lg — large surfaces, modals
  • --field-radius — form fields (HeroUI derived)

Elevation

Prefer borders and surface tokens over heavy multi-layer shadows. Use soft elevation for overlays (dropdown, modal, toast) only. Avoid neon glows.

Touch targets

Minimum interactive target: 44×44px on mobile. Icon-only buttons must meet this via padding or hit-area.
