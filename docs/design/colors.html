Colors

Nabta green maps to HeroUI --accent. Semantic roles only — no large raw palettes in product UI.

Portals theme via HeroUI CSS variables (oklch). Override after @import "@heroui/styles". Docs site keeps the same brand hex in its own CSS. See Theming.

Brand accent

TokenHex (human)Notes
--accent#10B981Nabta green — primary actions, focus, links
--accent-foreground#FFFFFFText/icons on accent
--accent-hover#059669Derived / explicit hover (~emerald-600)
--accent-soft / soft-foreground / soft-hover—Let HeroUI derive soft surfaces from accent

Use accent sparingly. Overuse weakens hierarchy in a calm school product.

Rules

  • Theme through CSS variables — never hardcode brand greens on one-off components
  • Do not introduce a second “primary” brand color
  • Docs site may keep #10b981 in docs/assets/docs.css; portals use HeroUI tokens

Light & dark mode

Required from Phase 1. Theme toggle in app shell. Respect prefers-color-scheme; persist preference. Both EN and AR must work in both themes; RTL in both themes.
