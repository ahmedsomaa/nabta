Design Philosophy

Modern · Calm · Premium · Academic · Professional

Two surfaces

Portals (apps/web, apps/marketing) use React 19 + Tailwind CSS v4 + HeroUI v3 (@heroui/react + @heroui/styles). Consume the library — don't reinvent primitives. Theme with Nabta tokens (--accent = #10B981).

Docs (docs/) use this pure HTML/CSS shell with the same emerald brand green — no React UI library, no Tailwind, no build step.

Portal components

Prefer HeroUI: Button, Input, Select, Combobox, Modal, Drawer, Dropdown, Tabs, Tooltip, Popover, Calendar, Date picker, Table, Card, Badge, Progress, Toast, Alert, Skeleton, Breadcrumbs, and related compound patterns. See HeroUI MCP / heroui-agents.md for the live catalog.

Navigation

Desktop: Persistent sidebar. Mobile: Bottom navigation for primary actions + drawer for secondary. Navigation changes by role.

Motion

HeroUI CSS for component animation. Framer Motion selectively for page transitions, sidebar, and shell motion (150–300ms). Support prefers-reduced-motion.

Icons: default to Lucide React (static). Use lucide-animated sparingly for hover micro-interactions in product UI. The brand mark stays the static Lucide Sprout — see Logos.

Responsive

Breakpoints: 1440+, 1280, 1024, 768, 480, 375. Mobile is not compressed desktop — redesign for touch. Minimum touch target: 44px.

Accessibility

WCAG-oriented: keyboard navigation, focus states, semantic HTML, ARIA where required, proper labels, accessible dialogs/tables, color contrast, reduced motion, screen reader compatibility.

Avoid

  • Generic dashboard templates, excessive gradients, neon colors
  • Huge shadows, excessive rounded cards
  • Gamification overload, visually noisy interfaces
