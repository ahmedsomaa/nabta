Typography

IBM Plex Sans (EN) and IBM Plex Sans Arabic (AR) — academic, bilingual, mapped to HeroUI type tokens.

Font families

  • English / UI: IBM Plex Sans — headings and body
  • Arabic: IBM Plex Sans Arabic — RTL content (same stack when lang="ar")
  • Code / mono: IBM Plex Mono or system monospace

Set HeroUI font family CSS variables to IBM Plex. In Figma, update the Typography collection font variable manually after Theme Sync.

Scale

Align portal type to HeroUI font-size tokens. Prefer weight and size over decoration. At most three weights on one screen (typically 400 / 500 / 600).

Hierarchy

Page titles are prominent but not oversized. Section headings use weight, not underlines or heavy color. Body text stays comfortable for long assignment and lesson reading.

RTL

Use logical CSS properties (ms-, me-, ps-, pe-). Arabic strings render with dir="rtl" where appropriate. See Internationalization.
