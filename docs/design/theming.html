Theming (HeroUI)

Portals use HeroUI v3 CSS-variable theming. Nabta overrides brand tokens; components stay stock HeroUI.

Install styles

Tailwind must come first, then HeroUI styles:

/* globals.css */
@import "tailwindcss";
@import "@heroui/styles";

Packages: @heroui/react, @heroui/styles, tailwind-variants, Tailwind CSS v4. React 19+. No HeroUI Provider in v3.

Nabta overrides

Override semantic tokens for light and dark (values as oklch or hex — HeroUI prefers oklch). Example skeleton:

:root {
  --accent: oklch(0.72 0.15 163); /* ≈ #10B981 */
  --accent-foreground: oklch(1 0 0);
  --background: oklch(0.985 0.001 106.423); /* stone-50 #fafaf9 */
  --foreground: oklch(0.216 0.006 56.043); /* stone-900 #1c1917 */
  --muted: oklch(0.553 0.013 58.071); /* stone-500 */
  --border: oklch(0.923 0.003 48.717); /* stone-200 */
  --surface: oklch(0.97 0.001 106.424); /* stone-100 */
  --overlay: oklch(0.985 0.001 106.423); /* stone-50 */
  --font-sans: "Quicksand", "Zain", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", ui-monospace, monospace;
}

html.dark {
  --accent: oklch(0.78 0.14 163); /* ≈ #34D399 */
  --accent-foreground: oklch(0.141 0.005 285.823); /* zinc-950 */
  --background: oklch(0.274 0.006 286.033); /* zinc-800 #27272a — stage */
  --foreground: oklch(0.967 0.001 286.375); /* zinc-100 */
  --muted: oklch(0.705 0.015 286.067); /* zinc-400 */
  --border: oklch(0.37 0.012 286); /* between zinc-700/800 */
  --surface: oklch(0.18 0.005 286); /* rail under zinc-900 */
  --overlay: oklch(0.32 0.007 286); /* menus / hovers */
}

Component conventions

  • Compound components (Card.Header, Modal.Content, …)
  • onPress for pressable controls (accessibility)
  • className for styling — not HeroUI v2 classNames
  • Do not fork HeroUI internals; compose and theme
