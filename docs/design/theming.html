Theming (HeroUI)

Portals use HeroUI v3 CSS-variable theming. Nabta overrides brand tokens; components stay stock HeroUI.

Install styles

Tailwind must come first, then HeroUI styles:

/* globals.css */
@import "tailwindcss";
@import "@heroui/styles";

Packages: @heroui/react, @heroui/styles, tailwind-variants, Tailwind CSS v4. React 19+. No HeroUI Provider in v3.

Nabta overrides

Override semantic tokens for light and dark (values as oklch or hex — HeroUI prefers oklch). Example skeleton:

:root {
  --accent: oklch(0.72 0.15 163); /* ≈ #10B981 */
  --accent-foreground: oklch(1 0 0);
  --background: oklch(0.985 0.004 95);
  --foreground: oklch(0.21 0 0);
  --font-sans: "IBM Plex Sans", "IBM Plex Sans Arabic", system-ui, sans-serif;
}

.dark {
  --accent: oklch(0.78 0.14 163); /* ≈ #34D399 */
  --accent-foreground: oklch(0.21 0 0);
  --background: oklch(0.16 0.01 160);
  --foreground: oklch(0.97 0 0);
}

Full token tables: Colors, Typography, Spacing.

Component conventions

  • Compound components (Card.Header, Modal.Content, …)
  • onPress for pressable controls (accessibility)
  • className for styling — not HeroUI v2 classNames
  • Do not fork HeroUI internals; compose and theme
