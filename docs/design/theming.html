Theming (HeroUI)

Portals use HeroUI v3 CSS-variable theming. Nabta overrides brand tokens; components stay stock HeroUI.

Install styles

Tailwind must come first, then HeroUI styles:

/* globals.css */
@import "tailwindcss";
@import "@heroui/styles";

Packages: @heroui/react, @heroui/styles, tailwind-variants, Tailwind CSS v4. React 19+. No HeroUI Provider in v3.

Component conventions

  • Compound components (Card.Header, Modal.Content, …)
  • onPress for pressable controls (accessibility)
  • className for styling — not HeroUI v2 classNames
  • Do not fork HeroUI internals; compose and theme

Web (oklch) vs Native (HSL)

Web student portal light accent is #3FAE6A. Docs site may still use #10B981. Implementation differs by platform:

SurfaceTheme mechanismAccent token
Web portalsHeroUI v3 CSS variables (hex light, oklch dark)--accent: #3fae6a (student light)
Mobile student, mobile staffHeroUI Native + Uniwind HSL semantic tokensAccent HSL aligned to Nabta green

Light canvas is mint off-white; views are white --surface. Dark stays zinc rail vs stage — see overrides above. Do not copy oklch literals into React Native — use HeroUI Native theme APIs and Uniwind classes instead.
