Icons

Use Lucide React (lucide-react) by default. Add lucide-animated only where hover motion helps affordance (empty states, CTAs, settings, notifications). Install one icon at a time via the shadcn registry CLI (not a UI kit):

npx shadcn@latest add "https://lucide-animated.com/r/<icon-name>.json"

Components land in components/icons/. The CLI adds motion if missing. Keep Framer Motion for page and layout transitions; HeroUI uses CSS for component animation; use motion only for lucide-animated icons.

Agent tooling

Official HeroUI MCP (.cursor/mcp.json → @heroui/react-mcp), Agent Skills under .agents/skills/heroui-react, and local docs index at heroui-agents.md. See Nabta AGENTS.md. Node.js 22+ required for the MCP server.

Data Responsibilities

PostgreSQL is the source of truth for all persistent academic data.

Redis is for cache, rate limiting, notification queues, background jobs, and frequently accessed dashboard data. Never use Redis as the primary database.
