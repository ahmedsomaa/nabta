Request Path

  1. Browser sends request to /api/v1/*
  2. NestJS controller receives request
  3. Auth guard validates JWT, extracts user + schoolId + role
  4. RBAC guard checks permissions
  5. Service executes domain logic with tenant-scoped queries
  6. Prisma queries PostgreSQL (always filtered by schoolId)
  7. Response returned as { data, meta }

Background Worker Path

  1. Domain event occurs (e.g. assignment published)
  2. Service enqueues job to BullMQ via Redis
  3. Worker picks up job
  4. Worker creates notification records in PostgreSQL
  5. Worker sends notification emails via Resend (EmailService)

Shared Packages

  • packages/database — Prisma schema, client, migrations (used by api)
  • packages/types — Shared TypeScript interfaces (used by web + api + mobile apps)
  • packages/validation — Shared Zod schemas (used by web + api + mobile)
  • packages/config — Environment config, constants (used by web + api)
  • packages/i18n — Shared EN/AR translations (used by web, marketing, system-admin, mobile)
