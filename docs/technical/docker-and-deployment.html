Local Development — Docker Compose

Single command to start the full local stack:

ServiceImage / BuildPurpose
postgrespostgres:16Primary database
redisredis:7Cache + BullMQ queues
miniominio/minioS3-compatible object storage
apiDockerfile.apiNestJS (hot-reload in dev)
webDockerfile.webNabta SPA
marketingDockerfile.marketingMarketing site (Phase 1b)
 
# Infrastructure only (postgres, redis, minio)
pnpm docker:up

# Full stack including apps (containers)
pnpm docker:up:full

# Local apps against Docker infra (preferred for day-to-day)
pnpm start

Production — AWS Reference Architecture

flowchart TB
  subgraph aws [AWS]
    CF[CloudFront CDN]
    S3Web[S3 - web + marketing]
    ALB[Application Load Balancer]
    ECS[ECS Fargate - api]
    RDS[(RDS PostgreSQL)]
    ElastiCache[(ElastiCache Redis)]
    S3Files[S3 - file storage]
    SM[Secrets Manager]
    R53[Route 53]
  end
  Users[Users] --> R53
  R53 --> CF
  CF --> S3Web
  CF --> ALB
  ALB --> ECS
  ECS --> RDS
  ECS --> ElastiCache
  ECS --> S3Files
  ECS --> SM
  • Compute: ECS Fargate for API containers
  • Frontend: S3 + CloudFront for web and marketing static assets
  • Database: RDS PostgreSQL (Multi-AZ for prod)
  • Cache: ElastiCache Redis
  • Files: S3 with pre-signed URLs
  • Secrets: AWS Secrets Manager for DB credentials, JWT secrets, PSP keys
  • DNS/TLS: Route 53 + ACM certificates

  • Cache: Memorystore Redis
  • Files: GCS with signed URLs
  • Secrets: GCP Secret Manager

Secrets & External Services

Store sensitive values in your platform's secret manager — not in Docker Compose files or committed .env files.

SecretWhereNotes
RESEND_API_KEYAPI container env / Secrets ManagerResend transactional email — not in Docker Compose
RESEND_FROM_EMAILAPI container envVerified sender domain (e.g. noreply@nabta.app)
JWT secrets, DB credentialsSecrets ManagerRotate in production

Health Checks

  • API: GET /api/v1/health — returns DB and Redis connectivity status
  • Docker: configure HEALTHCHECK in Dockerfiles
  • Load balancers: health check on /api/v1/health every 30s
