Environment Variables

All environment variables by phase. Document every var in .env.example as it is introduced.

Never commit secrets. Production values go in your platform's secret manager — not Docker Compose files. See Docker & Deployment.

Phase 1 — Foundation

VariableExamplePurpose
NODE_ENVdevelopmentRuntime environment
PORT3000API server port
DATABASE_URLpostgresql://user:pass@localhost:5432/nabtaPostgreSQL connection (Prisma)
REDIS_URLredis://localhost:6379Redis — cache, BullMQ queues
JWT_ACCESS_SECRETrandom 64-char stringAccess token signing
JWT_REFRESH_SECRETrandom 64-char stringRefresh token signing
JWT_ACCESS_EXPIRY15mAccess token TTL
JWT_REFRESH_EXPIRY7dRefresh token TTL
RESEND_API_KEYre_...Resend transactional email API key
RESEND_FROM_EMAILnoreply@nabta.appVerified sender address
MINIO_ENDPOINTlocalhostMinIO host (local dev)
MINIO_PORT9000MinIO port
MINIO_ACCESS_KEYminioadminMinIO access key
MINIO_SECRET_KEYminioadminMinIO secret key
MINIO_BUCKETnabta-filesDefault object storage bucket
MINIO_USE_SSLfalseSSL for MinIO (true in production S3/R2)
WEB_URLhttp://localhost:5173Portal app URL (CORS, email links)
API_URLhttp://localhost:3000API base URL (server-side references)
VITE_API_URLhttp://localhost:3000API base URL for Vite apps (apps/web)

Phase 1d / 1e — Mobile Apps

VariableExamplePurpose
EXPO_PUBLIC_API_URLhttp://localhost:3000API base URL for apps/mobile-student and apps/mobile-staff

Expo reads EXPO_PUBLIC_* at build time. On a physical device, use your machine's LAN IP instead of localhost.
