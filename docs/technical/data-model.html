Data Model

Core entities, relationships, and database conventions.

Conventions

  • UUIDs for public identifiers — do not expose sequential database IDs through APIs
  • createdAt and updatedAt timestamps on all entities
  • schoolId on all school-owned entities for multi-tenancy
  • Normalized relational models via Prisma
