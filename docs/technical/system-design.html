Each module owns: Controller, Service, DTOs, Validation, Database access, Domain logic. Avoid unnecessary coupling.

Multi-Tenancy

All school-owned entities include schoolId. Backend enforces tenant isolation on every query — never rely on frontend filtering.

flowchart LR
  Request[API Request] --> Guard[Auth Guard]
  Guard -->|extract schoolId from JWT| Service[Domain Service]
  Service -->|WHERE schoolId = user.schoolId| DB[(PostgreSQL)]

Never trust client-provided schoolId. Derive from authenticated user context.

RBAC

Centralized authorization with NestJS guards/decorators. Roles: STUDENT, TEACHER, ADMIN, SYSTEM_ADMIN. Platform routes skip TenantGuard. Permissions extensible (e.g. assignments.grade, attendance.write).

  • Frontend: controls UI visibility
  • Backend: enforces actual authorization
  • No hardcoded role checks in business logic

File Storage Interface

interface StorageService {
  getUploadUrl(key: string, mimeType: string): Promise<string>
  getDownloadUrl(key: string): Promise<string>
  delete(key: string): Promise<void>
}

Implementations: MinIO (local dev via Docker), S3Storage, R2Storage, GCSStorage. Business logic uses the interface, not the provider.

Structured File Keys

{schoolId}/
  materials/{subjectId}/{lessonId}/{uuid}.{ext}
  assignments/{assignmentId}/{uuid}.{ext}
  submissions/{assignmentId}/{studentId}/{uuid}.{ext}
  announcements/{announcementId}/{uuid}.{ext}
  avatars/{userId}.{ext}

Pre-signed URLs for upload/download. Never public buckets. DB stores storageKey, mimeType, size, checksum.

Search Abstraction

PostgreSQL full-text search initially. Interface allows swapping to Elasticsearch/OpenSearch later without changing business logic.

Notification Pipeline

flowchart LR
  Event[Domain Event] --> Queue[BullMQ via Redis]
  Queue --> Worker[Notification Worker]
  Worker --> DB[(Create Notification)]
  Worker --> Email[ResendEmailService]
  Email --> Resend[Resend API]

See Email (Resend) for the EmailService interface, templates, and env vars.

Grading Schemes

Configurable per school: percentage, letter grade, GPA, IB-style criteria, custom. Do not assume all schools use the same system.
